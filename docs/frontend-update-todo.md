# Frontend Update TODO

本文档记录 MoviePilot Web / 后端更新中发现的、当前不属于 TV 端兼容必修项，但后续可以评估是否跟进的功能候选。

这些条目不是当前版本必须实现的兼容修复。每次执行 `.agents/prompts/frontend-update.md` 的上游更新分析时，应重新检查本文件：如果发现新的功能候选、已有条目已经不适合 TV 端、或某项已经变成兼容必修项，直接更新本文件，并在报告中写明变更。不要再等一次同意。用户当次说「只分析」或「不要修改」时不改本文件。

## 维护规则

- 只记录判定为功能候选、可后续评估的功能。不记录已确认必须修的兼容问题，也不把暂不跟进写成新条目。
- 功能候选要写明它为什么可能适合 tvOS。已经判定为功能候选的，不能因为现有实现没坏而拒绝写入。
- 不把复杂后台管理能力默认列为 TV 端待办；除非它有明确的大屏使用场景。
- 每条 TODO 应包含来源、当前判断、TV 端需要评估的关键点。
- 更新本文件是上游更新分析的一部分：判定为功能候选的条目直接写入。不要再等一次同意。用户当次说「只分析」或「不要修改」时不改本文件。

## 待评估功能

### 后端连接状态与自动重连

- 来源：MoviePilot Web `v2.14.0 -> v2.14.4` 增加 `system/ping` 服务探测、在线/检查中/离线状态、退避重试和手动重试提示。
- 当前判断：TV 已有服务器信息、登录凭据刷新和请求失败提示，但没有全局后端连接状态或统一重连入口。
- 可评估方向：
  - 是否在现有通知层增加非阻塞连接提示，而不是新增独立离线页面。
  - 区分设备断网、请求超时、后端不可达和登录失效，避免把鉴权失败当成离线。
  - 使用有限频率的 `system/ping` 与退避重试，并在应用进入后台或退出登录后停止探测。

### Agent Assistant / Web Agent

- 来源：MoviePilot Web / Backend `v2.13.6 -> v2.13.14` 新增 Agent Assistant、会话历史、附件上传、音频输入输出等能力。
- 当前判断：偏 Web 交互和后台助手能力，不属于 TV 端兼容必修项。
- 可评估方向：
  - 是否存在适合遥控器/语音输入的大屏助手入口。
  - 是否只提供只读问答，避免在 TV 端执行复杂后台操作。
  - 是否需要复用后端 `AI_AGENT_ENABLE`、`AI_AGENT_HIDE_ENTRY`、音频能力开关。

### 通知中心与通知历史

- 来源：MoviePilot Web / Backend `v2.13.6 -> v2.13.14` 强化通知中心、通知历史和未读提示。
- 当前判断：TV 端已有本地错误通知机制，未实现完整通知中心。
- 可评估方向：
  - 是否需要一个只读通知列表，展示后台任务、订阅、下载结果。
  - 是否需要未读角标或系统页入口。
  - 是否避免把后台管理消息流直接搬到 TV 首屏。

### 下载任务高级字段与控制

- 来源：Backend `DownloaderTorrent` 新增 `save_path`、`content_path`、`category`、限速、trackers 等字段；Web 增加下载器后缀和更多下载控制。
- 当前判断：新增字段向后兼容，TV 当前下载列表可以继续忽略未知字段。
- 可评估方向：
  - 下载列表是否展示保存路径、分类、tracker 或限速信息。
  - 是否增加限速、标签、后缀等高级操作。
  - 是否保持 TV 下载页轻量，避免变成完整下载器管理后台。

### 媒体详情豆瓣短评与影评

- 来源：MoviePilot Web / Backend v3.1.7 在有豆瓣 ID 的媒体详情页展示短评和影评。接口是 `GET /douban/interests/{doubanid}/{type_name}` 与 `GET /douban/reviews/{doubanid}/{type_name}`，分页参数为 `start` 和 `count`。
- 当前判断：不属于兼容必修。TV 详情页没有评论区，现有浏览、订阅和搜索不依赖这两项。
- 可评估方向：
  - 遥控器上的长文本分页是否适合放在详情页，而不是做成独立管理页。
  - 作者头像使用后端返回的代理地址，不在客户端拼接豆瓣图片。
  - 没有豆瓣 ID 时不显示入口。

### 媒体卡片状态批量查询

- 来源：MoviePilot Backend `v3.2.1` 新增 `POST /media/status`（单次最多 50 项，按输入顺序返回 `item_id`、`subscribed` 和同来源各季订阅模式）；配套 Web `v3.2.2` 用它把媒体详情页和首页/探索页卡片的入库与订阅状态合并成一次请求，并在 `v3.2.1` 以下回退旧的 `/mediaserver/exists` + `/subscribe/media/{media_id}`。
- 当前判断：不属于兼容必修，暂时不跟进。TV 端目前只在媒体详情页查询状态，且只对电影发 `/mediaserver/exists`；详情页主体 `/media/{id}` 和应用内头像、订阅列表、分季页都走其他请求，改为批量接口最多只是把两个后台并行请求合成一个，每页省一次 DB 往返，用户可见的首屏速度、加载遮罩和按钮文案都没有变化。TV 的媒体卡片、媒体网格和首页目前不展示订阅或入库角标，不存在 Web 那种“每屏几十张卡片各查两次状态”的场景。
- 可评估方向：
  - 触发条件：TV 端决定在媒体卡片或分季页展示订阅/入库角标，或详情页 `/media/{id}` 不再返回订阅相关字段、迫使客户端拆出状态查询时，再重新评估。
  - 新接口只查本地数据库、不访问外部媒体服务器，与现有 `/mediaserver/exists` 的口径不同；切换前必须确认两条路径在“已入库/未入库/查询失败”三种结果上一致，不一致就保留旧路径。
  - 它返回的 `seasons` 只有季号与洗版模式、没有订阅记录 ID，不能替代分季页依赖的 `/subscribe/` 快照，也不能替代取消订阅前的严格身份确认；迁移只应覆盖“是否已订阅/是否已入库”这类布尔状态读取。
  - 这是 `v3.2.1` 起才成立的新行为，必须按后端版本做 `>= v3.2.1` 门禁：低于该版本、版本读不出或无法解析时走现有请求，未登记的更高版本（含热修复）可以启用。
  - 接口对 `media_source` / `media_id` 要求成对提供，单边身份或 `media_id` 为 `0` 会 422；豆瓣、Bangumi 来源识别出 TMDB ID 后的补查仍需等第一次结果返回后再发，不能合并进同一批。

### 搜索筛选新增“源”与“字幕（中字/特效）”维度

- 来源：MoviePilot Web `v3.2.2` 提交 `4797eda1 feat(search): 增加流媒体源与中字筛选`（#886）先新增两个维度：`webSource`（显示为“源”，取值 `meta_info.web_source`）和 `chineseSubtitle`（显示为“中字”，只按 `torrent_info.labels` 是否包含“中字”判定，不从片名或国语标签推断）。随后同一 Web 标签被上游重指后追加的提交 `1da03170 feat(search): 字幕筛选支持中字与特效`（#890）把该维度改名为 `subtitle`（显示为“字幕”），选项扩为“中字”“特效”两项并支持多选，判定仍只取自 `torrent_info.labels`，与资源卡片标签同源。已保存的筛选状态 `FilterState` 在旧记录缺少新维度时仍可恢复，原有筛选设置继续有效。
- 当前判断：不属于兼容必修。后端没有新增接口或必填字段，TV 不跟随也不会报错。TV 搜索过滤条目前只有 站点 / 剧集 / 分辨率 / 编码 / 版本 / 制作组 / 促销 七个维度，缺“源”和“字幕”；TV 的筛选状态只存在于搜索会话内存中、不持久化，所以 Web 那种“旧筛选设置迁移”的兼容问题在 TV 端不存在，本条只作为可选功能候选。“特效”是 #890 新增的字幕标签取值，与 `edition`（TV 的“版本”，资源类型+特效）和过滤规则里的 `SPECSUB`（特效字幕）不是同一维度，评估时不要合并。
- 可评估方向：
  - “字幕”是大屏浏览资源时的常见筛选诉求，但 TV 过滤条已有 7 个维度，再加两个会拉长过滤条或依赖“全部筛选”弹层；需要先确认遥控器焦点顺序与可达性，可优先只做“字幕”，并考虑“中字/特效”多选在遥控器上的交互（Web 是多选按钮组），“源”按实际使用频率再定。
  - “字幕”判定必须与 Web 口径一致：只认 `torrent_info.labels`，不从标题、描述或国语标签推断；同时确认 labels 缺失、大小写或空白差异时的取值和 Web 一致，避免出现 Web 没有的合并/推断选项。
  - `web_source` 可能为空或缺失。Web 的 `getFilterValues` 读 `meta_info.web_source`，空值返回空数组，不生成「无」；资源卡片也只在有值时展示。TV 若增加该维度，空值和缺失值不进入选项，也不提供「无」，只有非空平台名参与级联收敛（`disabledOptions`）。未选该维度时，这些资源仍保留在结果里。现有维度用 `ResourceResultSemantics.normalized` 把空值收成「无」，不能照搬到这里。
  - 实现落点：在 `ResourceResultSemantics.fields` 增加键并同步 `matches` 与过滤选项生成；Web 的筛选键已从 `chineseSubtitle` 改为 `subtitle`，TV 内部语义键可自行命名，但选项取值必须与 Web 一致。过滤状态保持内存态，不新增持久化或跨会话恢复逻辑。
  - `meta_info.web_source` 与 `torrent_info.labels` 在已登记版本区间内一直存在，不需要新增后端版本门禁；后续若发现某个来源恒不返回 labels，只影响该维度选项是否出现，不阻断主流程。

### 订阅日历与特殊季显示

- 来源：Web 在订阅日历、特殊季标签、订阅进度展示上有持续优化。
- 当前判断：目前不是 TV 端兼容阻断；订阅核心契约仍由 `docs/subscription-compatibility-checklist.md` 维护。
- 可评估方向：
  - 是否增加 TV 端订阅日历视图。

## 暂不作为 TV 功能待办

以下能力目前默认不进入 TV 功能 TODO；除非用户明确要求或后续发现明确的大屏使用场景：

- 插件市场 Release 安装、Wiki 同步、插件日志下载、插件 doctor。
- 站点、用户、工作流、通知渠道、插件配置等复杂后台管理页面。
- Web 主题、动画、移动端布局、PWA 安装提示等纯 Web 体验优化。
